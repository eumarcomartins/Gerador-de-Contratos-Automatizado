# Biblioteca Oficial de Cláusulas — Assessoria

Versão: 1.0.0

A fonte canônica e integral dos textos jurídicos é `legal/clause-library.json`. Este arquivo serve como índice humano; o renderer e os testes não devem extrair texto daqui.

Todos os textos com `locked: true` no JSON são imutáveis em runtime e protegidos por `legal/clause-hashes.json`.
