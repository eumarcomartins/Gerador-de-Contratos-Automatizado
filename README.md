# Rota Contract Generator

Specification-first repository for a deterministic Assessoria contract generator.

## Codex
Open this repository in OpenAI Codex. Codex reads `AGENTS.md`; use `MASTER_PROMPT.md` as the first implementation task.

## Safety
The app defaults to MOCK MODE.
Do not place real credentials in the repository.

## Product scope
Version 1.0.0 covers only ASSESSORIA.
Implementation-product contracts are intentionally out of scope.
