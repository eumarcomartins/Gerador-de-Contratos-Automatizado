# Versionamento Contratual

Todo contrato registra:
- contract_id
- spec_version
- clause_library_version
- business_rules_version
- validation_rules_version
- calculation_rules_version
- render_hash
- generated_at
- signature_date
- service_start_date

Mudança jurídica => nova versão da Clause Library.
Mudança comercial => nova Business Rules version.
Mudança só visual => não altera versão jurídica.

Contrato enviado à assinatura nunca é regenerado silenciosamente com especificação nova.
