# Acceptance Criteria

1. Closer não técnico completa PF/PJ sem editar JSON.
2. Combinações inválidas são bloqueadas.
3. 4+ áreas vão para manual.
4. Cláusulas seguem exatamente a matrix.
5. LLM não participa da composição jurídica em runtime.
6. Valores/datas usam pt-BR.
7. Signatários PF/PJ exatos.
8. Preview/PDF sem placeholders.
9. Mock ClickUp e ZapSign funcionam.
10. Adapters reais desabilitados por padrão.
11. UI segue a identidade Rota.
12. Gate automatizado passa.
13. `artifacts/pre-human-report.md` existe.
