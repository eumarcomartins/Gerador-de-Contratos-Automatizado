# Non-goals and deferred scope

## Fora do MVP v1.0.0

Edição manual do texto de cláusulas dentro da UI.
LLM em runtime para redigir contratos.
Suporte a 4 ou mais áreas.
Mais de uma PJ contratante no mesmo instrumento.
Mistura PF + PJ como contratantes no mesmo contrato.
RD Station no produto Assessoria.
Preço individual do Flowjuris.
Nova franquia automática de Landing Pages na renovação.
Banco de dados próprio para CRM de contratos.
Envio real a integrações durante testes automatizados.
Recriação aproximada do logotipo.

## Assinatura — follow-up

O objetivo maior do projeto contempla acompanhamento de assinatura em atraso, mas a cadência, canal e conteúdo desse follow-up ainda não foram especificados.

Consequentemente, o MVP pode:
receber status por webhook;
exibir status;
exibir há quanto tempo o documento aguarda assinatura.

O MVP NÃO deve inventar:
quantidade de lembretes;
prazo entre lembretes;
texto das mensagens;
canal automático;
regra de escalonamento.

Essa automação será uma extensão posterior quando a política for definida.
