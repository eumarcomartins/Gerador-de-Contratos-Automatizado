# Fase 3 — Interface

Implemente o wizard a partir de `spec/form-flow.json`.

Leia integralmente:
- `product/brand-tokens.json`
- `product/design-system.md`
- `product/ui-requirements.md`
- `product/ui-wireframe.md`
- `product/component-inventory.json`
- `product/ui-copy.md`

Requisitos inegociáveis:
- dark mode da Rota no aplicativo;
- desktop com formulário à esquerda e preview A4 persistente à direita;
- o preview começa desde o primeiro passo e é atualizado pelo mesmo motor determinístico do documento final;
- nenhuma regra de contrato pode ser duplicada em componentes React;
- nunca mostrar `{{PLACEHOLDER}}` ao usuário;
- dados ainda não definidos usam marcadores visuais UI-only;
- mudanças contratuais destacam temporariamente o trecho afetado;
- mobile alterna entre `Preenchimento` e `Contrato`;
- MOCK/LIVE sempre visível;
- fallback textual do logo até o SVG oficial existir;
- etapa final possui CTA `REVISAR E GERAR CONTRATO`;
- abrir modal obrigatório com resumo de todas as decisões variáveis;
- `GERAR CONTRATO` só habilita após validação integral + checkbox de confirmação;
- a confirmação cria aprovação para `payload_hash + render_hash`;
- qualquer alteração contratual posterior invalida a aprovação e exige nova revisão;
- confirmar o modal nunca dispara ClickUp ou ZapSign.

Implemente e teste os cenários de `tests/ui-behavior-cases.json`.

Não avance para integrações externas nesta fase.
