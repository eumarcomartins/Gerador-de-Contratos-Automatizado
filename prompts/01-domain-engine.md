# Fase 1 — Núcleo determinístico

Implemente o domínio antes da UI.

Use TypeScript estrito.
Implemente schemas, normalização, validação, cálculos, resolução de cláusulas, signatários, placeholders, render hash e workflow state machine.

Não use LLM.

Dinheiro em centavos/decimal seguro.
Datas ISO internamente.
Nenhuma regra duplicada em React.

Antes de encerrar, execute unit tests e mostre a rastreabilidade para BR/VR/CR.
