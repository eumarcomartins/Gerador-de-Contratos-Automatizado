# Design System — Rota Jurídica Contract Generator

## Fonte de verdade

Este documento traduz o Manual de Marca para decisões de interface. `product/brand-tokens.json` é a representação estruturada.

## Personalidade visual

Software B2B interno.
Corporativo.
Moderno.
Orientado a dados.
Sério sem parecer burocrático.
Tecnologia, consultoria, performance e operações — não estética jurídica tradicional.

## Cores

Primária: `#004366`
Alternativa primária: `#004467`
Fundo principal: `#111111`
Preto absoluto de apoio: `#000000`
Texto principal: `#FFFFFF`
Destaque/CTA: `#F2C94C`

O dourado é acento, não cor de superfície dominante.

## Tipografia

Títulos: Poppins.
Corpo e UI: DM Sans.

Carregar por fonte web quando disponível. Não versionar arquivos binários de fonte no repositório.

## Superfícies

Aplicação em dark mode.
Cards discretamente mais claros que o fundo.
Bordas finas de baixo contraste.
Sombras leves e apenas quando necessárias para hierarquia.

## Componentes

Header compacto.
Wizard com progresso.
Cards para grupos de dados.
Resumo lateral no desktop.
Drawer/accordion no mobile.
Preview em papel A4 branco.
Badge persistente e muito visível de MOCK/LIVE.
Alertas de regra manual em card de atenção.

## Ícones

Somente ícones lineares e minimalistas.
Não usar balança, martelo, colunas, pergaminho ou outros clichês jurídicos.

## Uso de espaço

Priorizar respiro.
Não comprimir formulários.
Agrupar campos por decisão, não por quantidade de espaço disponível.

## Logotipo

O arquivo oficial ainda não está no pacote.

Fallback temporário permitido:
`ROTA JURÍDICA` em lockup tipográfico.

Proibido:
redesenhar a marca;
gerar uma aproximação do símbolo;
usar um logo inventado.

Quando o usuário fornecer os arquivos oficiais, substituir:
`assets/logo-horizontal.svg`
`assets/logo-mark.svg`
`assets/favicon.svg`

## Acessibilidade

Contraste AA como mínimo.
Foco visível.
Labels persistentes.
Não usar somente cor para representar erro/estado.
Formulário navegável por teclado.
