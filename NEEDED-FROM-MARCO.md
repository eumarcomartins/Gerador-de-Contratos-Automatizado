# O que ainda será necessário fornecer

## Para o protótipo em MOCK

Nada obrigatório.

O pacote já contém:
regras;
cláusulas;
testes;
identidade visual textual;
fluxo;
schemas;
mocks;
instruções para Codex.

## Ativo visual recomendado

Logo oficial da Rota Jurídica.

Preferência:
SVG horizontal;
SVG da isomarca;
favicon SVG.

Se você só possuir PNG em alta resolução, pode fornecer também.

Não é necessário fornecer fontes.

## Para habilitar ClickUp LIVE depois da homologação

ClickUp API Token.
ClickUp List ID da List Cadastro.

Os IDs de Custom Fields poderão ser descobertos/validados pelo adapter com o token e a List, portanto não é obrigatório levantar tudo manualmente antes.

## Para habilitar ZapSign LIVE depois da homologação

ZapSign API Token.
E-mail que deve ser usado para o signatário da CONTRATADA, caso seja diferente do e-mail contratual.
URL pública do ambiente para webhook quando definida.

## Antes do uso com clientes reais

Aprovação humana do teste.
Revisão jurídica final da versão de produção.
Confirmação dos dados cadastrais fixos da CONTRATADA.

## Não envie agora

Tokens e segredos.
Eles só serão necessários quando a fase LIVE começar.
